# 코인베이스 현물 데이트레이딩 스캐너

유튜브 **매매법아카이브** 채널 영상 13개의 매매 규칙을 코인베이스 현물(롱 전용)용 **5분봉 + 1시간 추세 필터**로 옮긴 신호 프로그램입니다.
**주문은 하지 않습니다.** API 키도 필요 없습니다(공개 시세만 사용).

## 실행
```bash
cd /Users/jchun/trading
python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt   # 처음 한 번
./.venv/bin/python app.py          # 대시보드 → http://localhost:8765 자동으로 열림
./.venv/bin/python scan.py         # 대시보드 없이 터미널에 한 번만 출력
```
Finder에서 `start.command` 를 더블클릭해도 됩니다. (처음엔 우클릭 → 열기)

## 동작 순서 (스캔 1회)
1. 코인베이스 USD 현물 전체 (온라인·거래 가능·스테이블코인 제외, 약 400개) 조회
2. 각 코인 5분봉 300개 + 1시간봉 300개 수집 (1시간봉은 30분 캐시)
3. **백테스트(1시간마다)**: 거래대금 상위 30개 코인 × 최근 3일 5분봉으로 15개 전략을 수수료 포함 시뮬레이션
   (개장 돌파는 상위 10개 × 최근 7 평일 1분봉)
4. **시장 국면**: BTC 1시간 추세 + 전체 코인 중 1시간 상승추세 비율 + 변동성 → 상승/횡보/하락
5. **오늘의 전략 순위** = 0.5×(3일 성과) + 0.5×(최근 24시간 성과) + 국면 적합도
   - 표본이 적은 전략이 우연히 1등 하지 않도록 성과는 `합계 ÷ (거래수+5)`로 보수적으로 계산
6. **실시간 신호**: 전체 코인에서 방금 마감한 2봉 안에 나온 신호 → 전략 순위·유동성·1시간 추세로 점수화
7. 결과: `results/latest.json`, 신호 기록 `results/signals_YYYYMMDD.csv`

1회 스캔은 첫 실행 약 2~3분, 이후 약 1분(공개 API 초당 8회 제한). 대시보드는 5분봉 마감 15초 뒤마다 자동 스캔합니다.

신호가 뜬 코인마다 가장 좋은 신호 하나를 골라 100점 만점으로 다시 채점합니다.
- 기본 점수: 전략 순위 · 거래대금 · 1시간 추세 · 손절폭이 수수료보다 충분히 넓은지
- 가산: 이 코인에서 이 매매법이 최근 통했음 / 여러 매매법이 동시에 신호 / 수수료 뺀 손익비 1:2 이상 / BTC보다 강함 / 거래량 1.5배 이상
- 감점: 이 코인에서 최근 안 맞았음 / 손익비 1 미만 / 20이평에서 너무 멀어 추격 위험 / 시장 하락 국면
- 등급: A 80↑ · B 65↑ · C 50↑ · D. 맨 위 한 줄 판정(진입 검토 / 작게 / 관망)과 함께 손절·익절·권장 금액·손절 시 손실액을 보여 줍니다.
- `python3 scan.py` 로 터미널에서도 같은 TOP 5를 볼 수 있습니다.

## 텔레그램 알림 (1시간마다 자동)
1. 텔레그램에서 **@BotFather** → `/newbot` → 봇 이름을 정하면 토큰을 줍니다.
2. 터미널에서 `cd /Users/jchun/trading && ./install_hourly.sh`
   - 처음이면 토큰을 물어봅니다 → 붙여넣고, 만든 봇에게 아무 메시지나 보낸 뒤 엔터
   - 테스트 메시지가 오면 연결 완료. 바로 한 번 스캔해 보고, 이후 **매시 01분**마다 자동 실행됩니다.
3. 새 **A등급** 후보가 나올 때만 메시지가 옵니다. 같은 코인은 6시간 안에 다시 보내지 않습니다.
   - `telegram.json` 에서 `min_grade` 를 `"B"` 로 바꾸면 B등급도 받습니다. `cooldown_hours` 로 중복 간격 조절.
   - 손절폭이 수수료보다 좁거나 수수료 뺀 손익비가 1 미만인 신호는 A등급이 될 수 없습니다.
- 맥이 켜져 있어야 합니다(잠자기 중 놓친 실행은 깨어날 때 한 번 실행). 기록: `results/hourly.log`
- 대시보드(app.py)를 켜 두면 5분마다 스캔하면서 같은 규칙으로 알림을 보냅니다(중복 방지 공유).
- 해제: `./uninstall_hourly.sh`
- `telegram.json` 에는 봇 토큰이 들어 있으니 다른 사람과 공유하지 마세요.

## 맥 없이 무료로 돌리기 (GitHub Actions)
GitHub가 1시간마다 서버에서 `hourly.py` 를 대신 실행해 줍니다. 신용카드 필요 없음.
**공개(Public) 저장소는 Actions가 무료·무제한**이라 공개로 만드는 걸 권장합니다(코드만 공개, 토큰·계좌 금액은 Secrets로 숨김).

1. github.com 가입 → 오른쪽 위 **+ → New repository** → 이름 `coin-scanner`, **Public** → Create
2. 파일 올리기 (터미널):
   ```bash
   cd /Users/jchun/trading
   git init && git add . && git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<내아이디>/coin-scanner.git
   git push -u origin main
   ```
   (`.gitignore` 덕분에 telegram.json·.venv·결과 파일은 올라가지 않습니다. Finder 드래그로 올리면 숨김 폴더 `.github` 이 빠지니 터미널을 쓰세요.)
3. 저장소 **Settings → Secrets and variables → Actions**
   - Secrets: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (telegram.json 안의 값), 선택: `ACCOUNT_USD`
   - Variables(선택): `TELEGRAM_MIN_GRADE` = `B`, `FEE_PCT_PER_SIDE` = 본인 수수료
4. **Actions** 탭 → `hourly-scan` → **Run workflow** 로 한 번 실행해서 초록 체크가 뜨는지 확인
   - 실행 화면 아래 Summary에 그 시각의 TOP 5 표가 남습니다.
5. 이후 매시 07분쯤 자동 실행(GitHub 사정으로 5~20분 늦어질 수 있음).

참고
- 실행 1회 약 3~5분(코인 400개 수집). 공개 저장소면 무료, **비공개 저장소면 무료 한도를 넘을 수 있으니** 비공개를 원하면 `.github/workflows/scan.yml` 의 cron 을 `"7 */2 * * *"`(2시간마다)로 바꾸세요.
- 실행마다 `results/notified.json`(중복 알림 기록)을 커밋하므로 저장소가 계속 '활동 중'으로 유지됩니다. (공개 저장소는 오래 활동이 없으면 예약 실행이 꺼질 수 있음)
- GitHub Actions 서버도 미국에 있어 코인베이스 공개 API에 접속됩니다. 첫 실행에서 오류가 나면 Actions 로그를 확인하세요.
- 맥에서 launchd 로 돌리던 걸 GitHub로 옮기면 `./uninstall_hourly.sh` 로 맥 쪽은 꺼 주세요(알림 중복 방지 기록이 서로 공유되지 않음).

### 원본과 다른 점 (꼭 알아 두세요)
- 영상은 대부분 **4시간봉/일봉** 기준입니다. 5분봉으로 줄이면 신호가 많아지고 잡음도 많아집니다. 그래서 1시간 추세 필터와 백테스트 순위를 붙였습니다.
- 숏 규칙은 쓰지 않습니다(현물은 공매도 불가).
- 영상에 나오지 않은 값은 임의로 정했습니다: 훌 이동평균 55, 임마누엘 간격 0.3%(영상은 4시간봉 1%), 데이비드 폴 목표 1R(영상은 4시간봉 고정 2%), 세력 CCI는 VWMA 기준 CCI로 구현. 모두 `config.json` → `params` 에서 바꿀 수 있습니다.

## 꼭 바꿀 설정 (`config.json`)
- `fee_pct_per_side`: **본인 코인베이스 수수료 등급**. 기본값 0.6%는 보수적인 값입니다. 5분봉 단타에서 왕복 수수료는 수익의 대부분을 먹을 수 있어서, 메모에 "손절폭이 수수료 대비 좁음"이 뜨는 신호는 피하는 게 좋습니다. 지정가(maker) 주문을 쓰면 수수료가 낮아집니다.
- `account_usd`, `risk_per_trade_pct`: 권장 금액 계산용 (손절에 닿으면 계좌의 1%만 잃도록).
- `min_24h_volume_usd`: 이보다 거래대금이 작은 코인은 "저유동성"으로 표시하고 백테스트에서 제외.
- `enabled_strategies`: 비워 두면 전체, `["qullamaggie_box","testa_pullback"]` 처럼 골라 쓸 수 있음.
